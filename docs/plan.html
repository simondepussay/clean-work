就活パイロット（仮） 計画書

日本で就職活動をする留学生のための、応募管理・履歴書作成・ESレビュー・面接練習アプリ（iOS + Web）

2/20MVP公開予定 · 締切まで 39 日の余裕

1. 概要

だれのため？ 日本で就職活動をする留学生。履歴書の形式・ESの敬語・日本語の面接が大きな壁になっている。

なにを作る？ 応募管理、JIS形式の履歴書PDF、AIによるESレビュー（解説はフランス語・英語でも）、v1.1で音声の面接練習。

いつまで？ 3/31（サマーインターン応募開始（2027年4月〜）の前にMVP公開）。開発開始 2026-10-19。

見積もりの前提： 1人開発・授業と並行（週10〜12時間）。ベロシティ10SP/スプリント → 1SP ≒ 1.4日。ストーリーポイントはフィボナッチ数（1, 2, 3, 5, 8, 13）。

スプリントごとの負荷

ストーリーは完了したスプリントに数える。8 SPのストーリー（S11・S14）が終わるスプリントは負荷が高く（オレンジ）、その前は低い → スプリントプランニングで8 SP以上のストーリーを分割するのが次の改善。βテスト・審査待ちのスプリント（S8・S9）は開発が少ないので、v1.1の準備にあてる。

基本情報メモ： スクラムでは、スプリントごとに「スプリントプランニング → デイリースクラム → スプリントレビュー → レトロスペクティブ」を回す。ベロシティは「1スプリントで終わったSPの合計」で、実績から見積もりを直していく。

練習問題（この計画から）

Q1. クリティカルパスと、全体の最短日数は？

A → B → C → G → J → K → L → M（ダミー d1 を含む）。最短 82 日。最早結合点時刻と最遅結合点時刻が等しい結合点をたどる。

Q2. 作業E（履歴書PDF）が5日遅れたら、全体は何日遅れる？

Eの全余裕は 4 日なので、5 − 4 = 1 日遅れる。余裕の範囲内の遅れは全体に影響しない。

Q3. 作業D（応募管理）の全余裕日数は？

最遅開始日 25 − 最早開始日 21 = 4 日。

Q4. なぜダミー作業 d1（⑥→⑦）が必要？

ESレビュー（G）と履歴書PDF（E）はどちらも④から始まり⑦で終わる。アローダイアグラムでは同じ2つの結合点の間に2本の作業を引けないので、⑥を作ってダミーでつなぐ。所要日数は0日。

Q5. PERTでは82日なのに、ガントチャートでは長くなるのはなぜ？

PERTは「並行できる作業は同時に進める」前提（人数に制限なし）。実際は開発者が1人なので、開発作業を1本ずつ並べ直す（山崩し＝資源の平準化）。その結果 127 日になる。
